Four jobs the agent does so you don't have to

Reads your documents

Upload a citizen ID, income certificate or caste certificate. Gemini extracts your name, date of birth, state, category and income, and suggests a scheme that fits.

Finds schemes on myScheme

Use the dashboard discovery button to enter age, gender and state in the live myScheme finder and see matching schemes with links. The legacy portal agent remains available separately.

Fixes rejected forms

If the portal turns an entry down, the agent reads the error message, corrects the value and submits again, instead of stopping and asking you to start over.

Keeps a receipt trail

Each submission is saved with its receipt ID and SHA-256 signature, so you can look up what was filed and when.
